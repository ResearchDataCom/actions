# Images and Figures

Use [Scalable Vector Graphics (SVG)](https://www.w3.org/Graphics/SVG/)
if possible.  Make certain to [credit](../credits.md) the artists.

The web site [favicon.io](https://favicon.io/) can convert images into
favicons, but see also
["Open Source Favicon Generation & Optimization in 2024"](https://rodneylab.com/open-source-favicon-generation/)
for an option that uses free/libre/open source software.
